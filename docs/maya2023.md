# Maya 2023 — CurveNet deformer

This adapter is a Windows x64 research build. `cnProfileMover` is an
`MPxDeformerNode`: loading the plug-in registers the type, but does not create a
node or change a mesh. The solver receives a polygon mesh plus a graph of cubic
Bézier spans. Version 0.2.2 embeds the Python authoring helper in the `.mll`;
no separate script file is required at runtime.

## Load and bind your mesh and curves

Download `curvenet.mll` for Maya 2023. Restart Maya if an older CurveNet binary
is loaded. In Maya's Python Script Editor (replace the path with your file):

```python
import maya.cmds as cmds
cmds.loadPlugin(r"C:\CurveNet\curvenet.mll")
```

Loading registers `cnProfileMover`, the `cnBindSelection` command and a CurveNet
menu in GUI sessions. Maya 2023 runtime has not yet been validated on the build
machine; report any Script Editor error.

## Use one or more of your curves

Draw NURBS curves near the surface. Select **exactly one polygon mesh** and one
or more NURBS curve transforms, then choose **CurveNet > Bind selected mesh and
curves**, or run:

```python
cmds.cnBindSelection()
```

For explicit names and a returned dictionary of nodes/controls:

```python
import sys
cn = sys.modules['_curvenet_embedded']
rig = cn.bind_curves('Body', ['curve1', 'curve2', 'curve3'])
```

The helper snapshots the current mesh as the projection surface, converts degree
1 or 3 polynomial NURBS spans to cubic Bézier segments in mesh-local space,
welds coincident span endpoints, creates `cnProfileMover` after the existing
history, fills its attributes and connects generated direct knot/handle controls.
Move the knot controls to deform. A neutral binding does not move the mesh.

Curves are sampled **at bind time**; editing the original NURBS curves later is
not connected to the deformer. Animate the generated controls. Rational spans,
curves of other degrees, crossings inside spans without shared knots, overlaps,
projection jumps and topology changes are unsupported. Split curves at every
intersection so the crossing is a span endpoint and use compatible endpoints;
use the `weld_tolerance` argument for the intended scene scale. The deformer
does not currently display a viewport curve guide in Maya.

The solver transports offsets over upstream skin/cache positions. **Visible
control frames currently stay at the bind pose** when the upstream surface moves;
they do not yet follow its deformation. Check results on a copy of the scene.

## Diagnose

```python
import maya.cmds as cmds
print(cmds.pluginInfo('curvenet', query=True, dependNode=True))  # cnProfileMover
import sys
cn = sys.modules['_curvenet_embedded']
cn.diagnose((cmds.ls(type='cnProfileMover') or [])[0])
```

`projection_configured`, the control/spline/parent counts and connected matrices
describe setup; they are not proof that Maya has successfully evaluated the
solver. If another CurveNet binary is already loaded, restart Maya before loading
a different binary. The Type ID `0x0007F301` is reserved for local research and
must be replaced with a registered Autodesk ID before wider distribution.

## Build from source

Requirements: Windows x64, Visual Studio 2019/v142, CMake 3.24+, Eigen 3.4,
and the Maya 2023 SDK. Autodesk's
[SDK requirements](https://help.autodesk.com/cloudhelp/2023/ENU/Maya-SDK/files/Maya_SDK_MinimumRequirementsAllPlatforms_html.html)
specify Visual Studio 2019 for Maya 2023. In a VS2019 x64 developer environment:

```powershell
cmake -S . -B build-maya -G "Visual Studio 16 2019" -A x64 `
  -DCURVENET_MAYA=ON -DMAYA_ROOT="C:/path/to/maya2023/devkitBase"
cmake --build build-maya --config Release --target curvenet
ctest --test-dir build-maya -C Release --output-on-failure
```

`MAYA_ROOT/include/maya/MTypes.h` must report API 20230000; its `lib` directory
must contain Foundation, OpenMaya and OpenMayaAnim import libraries. The unpacked
module is in `build-maya/maya/`, with the `.mll` under `plug-ins/`. No SDK files
are shipped. Build a different adapter for any other Maya release.

To run the runtime test with Maya closed:

```powershell
& 'C:\Program Files\Autodesk\Maya2023\bin\mayapy.exe' `
  maya\tests\maya2023_smoke.py --plugin "C:/path/to/build-maya/maya/plug-ins/curvenet.mll"
```

The test creates a disposable scene and checks binding, offsets, envelope,
upstream blendshape, save/reopen and recovery from an invalid descriptor. A
successful SDK build or host-only test does not replace this runtime test.
